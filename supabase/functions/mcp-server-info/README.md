## لم يُعدَّل أي سلوك

اللقطة حرفية عمدًا. **لم يُغيَّر** أي دومين، أو `resource`، أو ترويسة،
أو منطق مصادقة/تفويض، أو أي إعداد إنتاج.

## ملاحظة على `_shared/tools-catalog-db.ts`

هذا الملف نسخة مكرَّرة من `supabase/functions/mcp/_shared/tools-catalog-db.ts`
(نفس أسلوب Edge Functions في تكرار الملفات المشتركة). كلتاهما تقرآن
جدول `public.mcp_tools_catalog` نفسه، فهو مصدر واحد وقت التشغيل.

## تعليق النسخة داخل الكود

هذا موجود في المصدر المنشور نفسه — تعليق قديم لم يُحدَّث — ولم تُدخِله اللقطة.
