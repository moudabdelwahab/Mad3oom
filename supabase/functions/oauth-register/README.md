## لم يُعدَّل أي سلوك

اللقطة حرفية عمدًا. **لم يُغيَّر** أي دومين، أو `resource`، أو ترويسة،
أو منطق مصادقة/تفويض، أو أي إعداد إنتاج.

## ملاحظة على `_shared/rate-limit.ts`

هذا الملف **ليس مطابقًا** لنسخة `oauth-token/_shared/rate-limit.ts`:
نسخة `oauth-register` تبدأ بتعليقين عربيين إضافيين، ونسخة `oauth-token` بدونهما.
كلتاهما محفوظتان كما هما بالضبط في الإنتاج — لا تُوحَّدا دون قرار صريح،
لأن أي توحيد يغيّر بايتات إحدى الدالتين المنشورتين.
