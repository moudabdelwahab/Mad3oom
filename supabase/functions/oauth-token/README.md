الدور: تبادل `authorization_code` بتوكن، وتدوير `refresh_token`.

## لم يُعدَّل أي سلوك

اللقطة حرفية عمدًا. **لم يُغيَّر** أي دومين، أو `resource`، أو ترويسة،
أو منطق مصادقة/تفويض، أو أي إعداد إنتاج.

## ملاحظات مثبتة من قراءة هذا المصدر

- **PKCE مُطبَّق فعليًا، لا مُعلَن فقط**: الدالة تحسب
  `sha256Base64Url(code_verifier)` وتقارنه بـ`code_challenge` المخزَّن.
- **لا يوجد أي ربط جمهور (audience binding)**: الدالة **لا تقرأ**
  المعامل `resource` إطلاقًا، والتوكنات المُصدَرة غير شفّافة
  (`mad3oom_bt_*`) ويُتحقَّق منها بمطابقة SHA-256 في جدول `api_tokens`،
  ولا يوجد `aud` في أي مسار. هذه ملاحظة توثيقية فقط وليست تغييرًا.
