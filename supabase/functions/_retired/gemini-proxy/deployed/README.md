اتحفظ لأن الدالة كانت منشورة **من غير أي مصدر في أي مستودع**. مفيش أي تعديل سلوك:
الملفات مكتوبة بايت-لبايت من مخرَج `get_edge_function` (مستخرَجة آليًا، مش منسوخة باليد).
