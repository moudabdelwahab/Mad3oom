# دليل نظام استيراد جهات الاتصال الاحترافي

## نظرة عامة

تم تطوير نظام احترافي متقدم لاستيراد جهات الاتصال في صفحة "إرسال رسالة" يدعم:

- ✅ استيراد من ملفات Excel و CSV و Google Sheets
- ✅ الاكتشاف التلقائي لعمود أرقام الهاتف
- ✅ تنظيف وتوحيد تنسيق الأرقام
- ✅ التحقق التلقائي من صحة الأرقام
- ✅ حذف الأرقام المكررة تلقائياً
- ✅ معاينة شاملة قبل الاستيراد (صالح - مكرر - غير صالح)
- ✅ ربط أعمدة الملف بمتغيرات قوالب الواتساب
- ✅ إنشاء تقارير مفصلة بنتائج الاستيراد والإرسال
- ✅ عدم التأثير على الوظائف الحالية

## المكونات الجديدة

### 1. **ContactImporter.js** (`utils/ContactImporter.js`)

فئة متخصصة في معالجة استيراد جهات الاتصال:

#### الوظائف الرئيسية:

```javascript
// قراءة الملف
await importer.readFile(file);

// الاكتشاف التلقائي لعمود الهاتف
importer.autoDetectPhoneColumn();

// تنظيف وتوحيد الأرقام
const normalized = importer.normalizePhoneNumber('+966 50 123 4567');
// النتيجة: '966501234567'

// معالجة البيانات والتحقق
const stats = importer.process(phoneColumn, mapping);
// stats = {
//   total: 100,
//   valid: [...],      // الأرقام الصحيحة
//   invalid: [...],    // الأرقام غير الصحيحة
//   duplicates: [...]  // الأرقام المكررة
// }

// إنشاء ملخص HTML
const summary = importer.generateSummaryHTML();
```

#### ميزات التنظيف:

- إزالة المسافات والأقواس والشرطات
- تحويل الأرقام التي تبدأ بـ 00 إلى صيغة بدون بادئة
- إضافة رمز الدولة تلقائياً (افتراضياً 966 للسعودية)
- التحقق من طول الرقم (8-15 رقم)

## واجهة المستخدم

### خيارات الاستيراد

في صفحة "إرسال رسالة"، ستجد قسماً محسناً للأرقام المستقبلة يحتوي على:

#### 1. **استيراد من ملف**
```
[📥 استيراد Excel / CSV]
```
- اختر ملف Excel (.xlsx, .xls) أو CSV
- سيتم الاكتشاف التلقائي لعمود الهاتف
- عرض معاينة شاملة قبل التأكيد

#### 2. **إدخال يدوي**
```
[✏️ إدخال يدوي]
```
- أدخل الأرقام يدوياً (رقم في كل سطر)
- يتم تنظيفها وتوحيدها تلقائياً
- دعم صيغ متعددة (مع/بدون رمز الدولة)

### معاينة الاستيراد

بعد اختيار ملف، ستظهر نافذة معاينة تحتوي على:

```
┌─────────────────────────────────┐
│ إعدادات الاستيراد              │
├─────────────────────────────────┤
│ عمود رقم الهاتف: [Phone ▼]     │
│                                 │
│ ربط متغيرات القالب:             │
│ المتغير {{1}}: [Name ▼]        │
│ المتغير {{2}}: [City ▼]        │
│                                 │
│ [تأكيد الاستيراد]              │
└─────────────────────────────────┘
```

#### الخيارات:
- **عمود رقم الهاتف**: اختر العمود الذي يحتوي على الأرقام
- **ربط المتغيرات**: ربط أعمدة الملف بمتغيرات القالب (مثل الاسم والمدينة)
  - اختر قيمة ثابتة من المدخلات أعلاه، أو
  - اختر عمود من الملف لاستخدام قيمة مختلفة لكل جهة اتصال

### ملخص النتائج

بعد الاستيراد، ستظهر بطاقة ملخص:

```
┌──────────────┬──────────────┬──────────────┐
│   صالح       │   مكرر       │  غير صالح   │
│   ✅ 95      │   ⚠️ 3      │   ❌ 2      │
└──────────────┴──────────────┴──────────────┘
```

## سير العمل الكامل

### الخطوة 1: اختيار القالب

```
1. اذهب إلى صفحة "إرسال رسالة"
2. اختر قالب الرسالة المراد استخدامه
3. ملاحظة: إذا كان القالب يحتوي على متغيرات ({{1}}, {{2}})، 
   ستظهر خيارات الربط بعد استيراد الملف
```

### الخطوة 2: استيراد جهات الاتصال

```
1. انقر على [📥 استيراد Excel / CSV]
2. اختر ملف Excel أو CSV من جهازك
3. سيتم الاكتشاف التلقائي لعمود الهاتف
4. تحقق من الإعدادات في نافذة المعاينة
5. انقر [تأكيد الاستيراد]
```

### الخطوة 3: ربط المتغيرات (اختياري)

```
إذا كان القالب يحتوي على متغيرات:

1. في نافذة المعاينة، ستجد قسم "ربط متغيرات القالب"
2. لكل متغير ({{1}}, {{2}}, إلخ):
   - اختر عمود من الملف، أو
   - استخدم القيمة الثابتة من المدخلات أعلاه
3. مثال:
   - {{1}} (الاسم) ← من عمود "Full Name"
   - {{2}} (المدينة) ← قيمة ثابتة "الرياض"
```

### الخطوة 4: فحص الأرقام

```
1. انقر على [فحص الأرقام]
2. سيتم التحقق من جميع الأرقام تلقائياً
3. ستظهر النتائج في قسم "إحصائيات الحملة"
```

### الخطوة 5: الإرسال

```
1. انقر على [إرسال الرسائل]
2. سيتم إرسال الرسائل مع المتغيرات المخصصة لكل جهة اتصال
3. ستظهر نافذة التقدم مع عدد الرسائل المرسلة
4. بعد الانتهاء، ستظهر رسالة النجاح مع عدد الرسائل الناجحة والفاشلة
```

## أمثلة الملفات المدعومة

### مثال 1: ملف Excel بسيط

| Phone | Name | City |
|-------|------|------|
| 0501234567 | أحمد | الرياض |
| +966-50-9876543 | فاطمة | جدة |
| 966501111111 | محمد | الدمام |

**النتيجة:**
- تم الاكتشاف التلقائي لعمود "Phone"
- تم تنظيف جميع الأرقام إلى صيغة موحدة
- يمكن ربط "Name" بـ {{1}} و "City" بـ {{2}}

### مثال 2: ملف CSV

```csv
رقم_الهاتف,الاسم,البريد_الإلكتروني
0501234567,أحمد محمد,ahmed@example.com
0509876543,فاطمة علي,fatima@example.com
```

### مثال 3: Google Sheets

1. قم بتصدير الورقة كـ CSV أو Excel
2. اتبع نفس الخطوات أعلاه

## معالجة الأخطاء

### أرقام غير صحيحة

يتم رفض الأرقام التي:
- تحتوي على أقل من 8 أرقام
- تحتوي على أكثر من 15 رقم
- تحتوي على أحرف (ما عدا الرموز مثل +، -)

### أرقام مكررة

- يتم اكتشاف التكرارات تلقائياً
- تظهر في قسم "مكرر" في الملخص
- يتم حذفها من قائمة الإرسال

### ملفات فارغة

- سيظهر خطأ "الملف فارغ"
- تحقق من أن الملف يحتوي على بيانات

## التقارير

### ملخص الاستيراد

بعد كل استيراد، يتم عرض:
- عدد الأرقام الصحيحة
- عدد الأرقام المكررة
- عدد الأرقام غير الصحيحة

### تقرير الإرسال

بعد إرسال الرسائل:
- عدد الرسائل الناجحة
- عدد الرسائل الفاشلة
- تفاصيل كل رسالة (في صفحة التقارير)

### حفظ التقارير

يتم حفظ جميع التقارير تلقائياً في قاعدة البيانات:
- اسم الحملة
- اسم القالب
- عدد المستقبلين
- عدد الناجح والفاشل
- بيانات وصفية (المتغيرات، مصدر الاستيراد)

## الميزات المتقدمة

### 1. الاكتشاف الذكي لعمود الهاتف

النظام يبحث عن:
1. أسماء الأعمدة التي تحتوي على: "phone", "mobile", "tel", "هاتف", "جوال"
2. محتوى البيانات الفعلي (أول 10 صفوف)
3. يختار العمود الأكثر احتمالاً

### 2. تنسيق الأرقام الذكي

- يدعم صيغ متعددة:
  - `0501234567` (محلي)
  - `+966501234567` (دولي)
  - `966501234567` (بدون +)
  - `00966501234567` (بادئة 00)
  - `050-123-4567` (مع فواصل)
  - `050 123 4567` (مع مسافات)

### 3. ربط المتغيرات المرن

- يمكن استخدام قيم ثابتة لجميع الرسائل
- أو قيم مختلفة من الملف لكل جهة اتصال
- أو خليط من الاثنين

### 4. عدم كسر الوظائف الحالية

- الإدخال اليدوي السابق يعمل كما هو
- جميع الأزرار والخيارات السابقة محفوظة
- التوافقية الكاملة مع الكود القديم

## استكشاف الأخطاء

### المشكلة: لم يتم اكتشاف عمود الهاتف

**الحل:**
1. تأكد من أن الملف يحتوي على عمود بأرقام هاتف
2. تأكد من أن الأرقام بصيغة صحيحة (8-15 رقم)
3. اختر العمود يدوياً من قائمة "عمود رقم الهاتف"

### المشكلة: جميع الأرقام تظهر كـ "غير صحيحة"

**الحل:**
1. تحقق من صيغة الأرقام
2. تأكد من أن الأرقام تحتوي على 8-15 رقم فقط
3. جرب إزالة الرموز الإضافية يدوياً

### المشكلة: الأرقام المكررة لا تُحذف

**الحل:**
- النظام يكتشفها ويعرضها في الملخص
- يتم حذفها تلقائياً من قائمة الإرسال
- تحقق من قسم "مكرر" في الملخص

### المشكلة: المتغيرات لا تظهر

**الحل:**
1. تأكد من أن القالب يحتوي على متغيرات ({{1}}, {{2}})
2. اختر قالب جديد وحاول مرة أخرى
3. تحقق من أن الملف يحتوي على أعمدة للربط
