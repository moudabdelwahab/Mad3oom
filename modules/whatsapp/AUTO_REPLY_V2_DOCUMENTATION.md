# نظام الرد الآلي المحسّن - نسخة SaaS

## 📋 نظرة عامة

تم تطوير نسخة محسّنة وشاملة من نظام الرد الآلي لمنصة mad3oom.online بمستوى احترافي يحاكي أنظمة SaaS العملاقة مثل Intercom و ManyChat و Chatbot.com.

### الميزات الرئيسية

- **محرر بصري متقدم**: واجهة سحب وإفلات احترافية لبناء التدفقات
- **عقد متنوعة**: 10 أنواع من العقد المتخصصة
- **نظام الخصائص**: لوحة جانبية لتعديل خصائص العقد بسهولة
- **التاريخ والتراجع**: نظام Undo/Redo كامل
- **اختبار التدفق**: محاكاة التدفق قبل النشر
- **محرك تنفيذ متقدم**: يدعم التدفقات المعقدة والحلقات والشروط
- **دعم الذكاء الاصطناعي**: تكامل مع OpenAI GPT
- **الحفظ التلقائي**: حفظ تلقائي مع مؤشرات الحالة

محرك تنفيذ التدفقات الذي يدعم:
- تنفيذ التدفقات المعقدة

- توليد الردود الذكية بـ AI
- التأخيرات والتوزيع العشوائي

#### 3. flow-editor-v2.css
نظام التصميم الاحترافي يتضمن:
- متغيرات CSS موحدة
- رسوم متحركة سلسة
- استجابة للشاشات المختلفة
- أنماط مظهر داكن وفاتح

## 🎯 أنواع العقد المدعومة

### 1. عقدة البداية (Start Node)
```
الرمز: 🏁
الوصف: نقطة دخول التدفق
المدخلات: لا توجد
المخرجات: 1
```

### 2. عقدة النهاية (End Node)
```
الرمز: 🛑
الوصف: إنهاء التدفق
المدخلات: 1
المخرجات: لا توجد
```

### 3. عقدة الرسالة النصية (Message Node)
```
الرمز: 💬
الوصف: إرسال رسالة نصية
المدخلات: 1
المخرجات: 1
الخصائص:
  - message: نص الرسالة
  - delay: تأخير بالثواني (0-300)
```

### 4. عقدة الوسائط (Media Node)
```
الرمز: 🖼️
الوصف: إرسال صور أو فيديوهات أو ملفات
المدخلات: 1
المخرجات: 1
الخصائص:
  - mediaType: image | video | document
  - mediaUrl: رابط الوسائط
  - caption: تعليق اختياري
```

### 5. عقدة الأزرار التفاعلية (Buttons Node)
```
الرمز: 🔘
الوصف: إرسال رسالة مع أزرار تفاعلية
المدخلات: 1
المخرجات: 1
الخصائص:
  - message: نص الرسالة
  - buttons: قائمة الأزرار (مفصولة بفاصلة)
```

### 6. عقدة الشرط (Condition Node)
```
الرمز: ⚖️
الوصف: تقسيم التدفق بناءً على شرط
المدخلات: 1
المخرجات: 2 (نعم/لا)
الخصائص:
  - keyword: الكلمة المفتاحية
  - matchType: contains | equals | startsWith
```

### 7. عقدة التأخير (Delay Node)
```
الرمز: ⏱️
الوصف: إضافة تأخير في التدفق
المدخلات: 1
المخرجات: 1
الخصائص:
  - seconds: عدد الثواني (1-300)
```

### 8. عقدة التوزيع العشوائي (Random Node)
```
الرمز: 🎲
الوصف: توزيع عشوائي للرسائل (A/B Testing)
المدخلات: 1
المخرجات: 2 (مسار A/B)
الخصائص:
  - ratio: نسبة المسار A (0-100%)
```

### 9. عقدة طلب HTTP (HTTP Node)
```
الرمز: 🌐
الوصف: إرسال طلب HTTP إلى API خارجي
المدخلات: 1
المخرجات: 1
الخصائص:
  - url: رابط API
  - method: GET | POST
  - timeout: المهلة الزمنية (1-60 ثانية)
```

### 10. عقدة الذكاء الاصطناعي (AI Node)
```
الرمز: 🤖
الوصف: توليد رد ذكي باستخدام AI
المدخلات: 1
المخرجات: 1
الخصائص:
  - prompt: التعليمات للـ AI
  - model: gpt-3.5-turbo | gpt-4
  - temperature: درجة الإبداع (0-1)
```

## 🚀 كيفية الاستخدام

### 1. فتح محرر الرد الآلي
```javascript
import { AutoReplyPageV2 } from './pages/AutoReplyPageV2.js';

const container = document.getElementById('auto-reply-container');
const page = new AutoReplyPageV2(container);
await page.load();
```

### 2. إضافة عقدة
اسحب عقدة من الشريط الجانبي وأفلتها على لوحة الرسم.

### 3. ربط العقد
اسحب من نقطة الإخراج (●) في عقدة إلى نقطة الإدخال (●) في عقدة أخرى.

### 4. تعديل الخصائص
انقر على عقدة لفتح لوحة الخصائص على اليمين.

### 5. اختبار التدفق
انقر على زر "اختبار" وأدخل رسالة اختبار.

### 6. حفظ التدفق
انقر على "حفظ الآن" أو اعتمد على الحفظ التلقائي.

## 🔧 تنفيذ التدفق

### استخدام محرك التنفيذ

```javascript
import { autoReplyEngine } from './services/auto-reply-engine.js';

// تنفيذ التدفق
const flow = await fetchFlowFromDatabase(userId);
const result = await autoReplyEngine.executeFlow(
    flow,
    'مرحبا',  // الرسالة الواردة
    userId
);

// معالجة النتائج
result.responses.forEach(response => {
    if (response.type === 'text') {
        console.log('إرسال:', response.content);
    } else if (response.type === 'media') {
        console.log('إرسال وسائط:', response.url);
    }
});
```

### التحقق من صحة التدفق

```javascript
const errors = autoReplyEngine.validateFlow(flow);
if (errors.length > 0) {
    console.error('أخطاء في التدفق:', errors);
}
```

## 📊 أمثلة على التدفقات

### مثال 1: رد بسيط
```
البداية → رسالة ("مرحبا! كيف يمكننا مساعدتك؟") → النهاية
```

### مثال 2: رد مع شرط
```
البداية → شرط (كلمة مفتاحية: "السعر")
    ├─ نعم → رسالة ("سعرنا هو...") → النهاية
    └─ لا → رسالة ("هل يمكنك توضيح أكثر؟") → النهاية
```

### مثال 3: رد ذكي مع تأخير
```
البداية → تأخير (2 ثانية) → AI Node → رسالة → النهاية
```

### مثال 4: اختبار A/B
```
البداية → توزيع عشوائي (50%)
    ├─ مسار A → رسالة ("النسخة A") → النهاية
    └─ مسار B → رسالة ("النسخة B") → النهاية
```

## 🔐 الأمان والأداء

### حدود الأمان
- **المهلة الزمنية القصوى**: 30 ثانية لتنفيذ التدفق
- **حد أقصى للتأخير**: 10 ثواني لكل عقدة تأخير
- **حد أقصى لطلبات HTTP**: 60 ثانية للمهلة الزمنية
- **منع الحلقات اللانهائية**: الكشف التلقائي عن الحلقات

### الأداء
- **الحفظ التلقائي**: كل 2 ثانية من عدم النشاط
- **تخزين مؤقت للتدفقات**: تخزين مؤقت في الذاكرة لتقليل استدعاءات قاعدة البيانات
- **سجل التنفيذ**: الاحتفاظ بآخر 1000 تنفيذ

## 🐛 استكشاف الأخطاء

### الخطأ: "لم يتم العثور على نقطة البداية"
**السبب**: التدفق لا يحتوي على عقدة بداية
**الحل**: أضف عقدة بداية من الشريط الجانبي

### الخطأ: "تم اكتشاف حلقة لا نهائية"
**السبب**: التدفق يحتوي على حلقة دائرية
**الحل**: تحقق من الاتصالات وأزل الحلقات

### الخطأ: "فشل الحفظ التلقائي"
**السبب**: مشكلة في الاتصال بقاعدة البيانات
**الحل**: تحقق من الاتصال بالإنترنت وحاول مرة أخرى
