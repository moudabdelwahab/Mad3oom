العناوين الأساسية #

الدومين الرسمي للمنصّة هو mad3oom.com. كل مسارات MCP وOAuth تُخدَم منه مباشرة بلا أي إعادة توجيه.

POST https://mad3oom.com/mcp

الدومين القديم mad3oom.online انتهى ولم يعد يُستخدم. لو عندك كود أو Connector قديم بيشاور عليه، بدّله بـ mad3oom.com فورًا. الطلبات القديمة كانت بتمرّ على إعادة توجيه 301 تحوّل الـPOST إلى GET (سلوك مواصفة Fetch)، فكان الخادم يرد 405 Only POST is supported على طلب أُرسل أصلًا كـPOST.

المصادقة والمفاتيح #

كل طلب على /mcp لازم يحمل ترويسة Authorization. مفيش استثناء — الطلب بلا ترويسة بيرجع 401.

Required header
Authorization: Bearer <credential>
Content-Type: application/json

نوعا الاعتماد

لوحة المطوّرين بتولّد نوعين من الاعتماد — الخادم بيقبل الاتنين على نفس الترويسة، ويفرّق بينهم بوجود نقطة . في القيمة.

النوعشكل القيمةالترويسة
API Key + Secret
credential_type: api_key_secret		 mad3oom_pk_<32 hex>
mad3oom_sk_<40 حرف>		 Bearer mad3oom_pk_….mad3oom_sk_…
Bearer Token
credential_type: bearer		 mad3oom_bt_<64 hex> Bearer mad3oom_bt_…

السرّ (mad3oom_sk_…) والـ Bearer Token بيظهروا مرة واحدة فقط لحظة الإنشاء. المخزَّن في قاعدة البيانات بصمة SHA-256 لا القيمة نفسها — فلا الخادم ولا فريق الدعم يقدر يعرضهم لك تاني. لو ضاع منك، ولّد مفتاح جديد أو جدّد السرّ.

بروتوكول JSON-RPC #

كل شيء بيمرّ من POST /mcp بجسم JSON-RPC 2.0 واحد. الـmethod بتحدّد العملية.

MethodالوظيفةHTTP عند النجاح
initializeالتفاوض على نسخة البروتوكول وبدء جلسة200
notifications/initializedإشعار من العميل بانتهاء التهيئة (بلا جسم رد)202
tools/listالأدوات المتاحة لمفتاحك200
tools/callتنفيذ أداة200

طلبات الدفعات (Batch) غير مدعومة. كل طلب HTTP لازم يحمل كائن JSON-RPC واحد — مش مصفوفة. وأي method غير الأربعة فوق بترجع 404 مع -32601. وGET /mcp بيرجع 405.

initialize

اختياري للاستخدام المباشر، لكنه إلزامي لو بتبني عميل MCP كامل. بيرجّع نسخة البروتوكول المتفق عليها وترويسة Mcp-Session-Id.

Request
POST /mcp
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18"
  }
}
Response
200 OK
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "protocolVersion": "2025-06-18",
    "capabilities": { "tools": {} },
    "serverInfo": {
      "name": "mad3oom-mcp",
      "version": "1.1.0"
    }
  }
}

النسخ المدعومة: 2025-06-18 (الافتراضية)، 2025-03-26، 2024-11-05، 2025-11-25. لو بعتّ نسخة غير معروفة، الخادم بيرجع للافتراضية بدل ما يرفض الطلب. الخادم يعلن قدرة tools فقط — لا resources ولا prompts.

tools/list

بيرجّع مصفوفة الأدوات بعد فلترتين: أدوات مفتاحك يملك صلاحيتها، وغير مُعطَّلة من إدارة المنصّة. كل عنصر فيه name وdescription وinputSchema (JSON Schema).

الكتالوج بيتقري من قاعدة البيانات مع كاش 30 ثانية — فأي تعديل من الإدارة بيبان خلال نصف دقيقة على الأكثر. اعتبر tools/list هو مصدر الحقيقة وقت التشغيل، وهذه الصفحة مرجعًا للشرح.

tools/call

بياخد params.name (اسم الأداة) وparams.arguments (كائن المعاملات).

شكل الطلب العام
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "<tool_name>",
    "arguments": { … }
  }
}

شكل الرد مهم: نتيجة الأداة بترجع كنص JSON جوه result.content[0].text، مش ككائن مباشر. لازم تعمل JSON.parse() عليها.

الرد الخام
200 OK
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "[\n  {\n    \"id\": \"…\"\n  }\n]"
      }
    ]
  }
}
استخراج البيانات
JavaScript
const { result, error } = await res.json();
if (error) throw new Error(error.message);

// نتيجة الأداة نص JSON — لازم parse
const data = JSON.parse(result.content[0].text);

في كل أمثلة مرجع الأدوات تحت، «الرد» معروض بعد هذا الـ parsing مباشرةً.

async function callTool(name, args = {}) {
  const res = await fetch("https://mad3oom.com/mcp", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${token}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      jsonrpc: "2.0", id: Date.now(),
      method: "tools/call", params: { name, arguments: args },
    }),
  });

  // 429 قابل لإعادة المحاولة — بقية الأخطاء لا
  if (res.status === 429) throw new Error("RATE_LIMITED");

  const data = await res.json();

  // أخطاء كتير بترجع HTTP 200 — الفحص على الجسم لا على res.ok
  if (data.error) {
    throw new Error(`[${data.error.code}] ${data.error.message}`);
  }

  return JSON.parse(data.result.content[0].text);
}

الترقيم (Pagination)

كل الأدوات اللي بترجع قوائم بتاخد limit وoffset. الافتراضي limit=20 وoffset=0، والحد الأقصى limit=100 — أي رقم أكبر بيتقصّ بصمت لـ 100، فلا تفترض إنك هتستقبل 500 صف.

إعادة المحاولة والتكرار

مفيش Idempotency Key على واجهة MCP. لو عملت retry على create_ticket أو send_whatsapp بعد انقطاع، ممكن العملية تتكرّر فعليًا. لو الـ retry مهم لك: تحقّق من عندك قبل الإرسال، أو استخدم Integration API لرسائل واتساب — فيها منع تكرار مدمج.

أعد المحاولة على 429 و5xx فقط، بتراجع أُسّي (2s، 4s، 8s، 16s) وبحد أقصى 5 محاولات. أخطاء 4xx الأخرى تحتاج إصلاح الطلب نفسه — إعادة المحاولة لن تغيّر النتيجة.

التدفّق

الاكتشاف

أول POST /mcp بلا توكن بيرجع 401 مع ترويسة WWW-Authenticate: Bearer resource_metadata="…" تدلّك على نقطة الاكتشاف. من هنا يبدأ أي عميل MCP قياسي تلقائيًا.

تسجيل العميل — POST /oauth/register

ابعت client_name وredirect_uris (لازم HTTPS) → بيرجع 201 مع client_id.

موافقة المستخدم — GET /oauth/authorize

PKCE إجباري بـcode_challenge_method=S256. المستخدم بيوافق من صفحة الموافقة، وبيرجع code على الـ redirect URI.

تبادل الكود — POST /oauth/token

بيرجع access_token صالح 3600 ثانية وrefresh_token صالح 30 يومًا. التوكن بيتسجّل في نفس جدول api_tokens، فبيشتغل على /mcp زي أي مفتاح.

التجديد

grant_type=refresh_token. الـ refresh token يُدوَّر بالكامل عند كل استخدام — القديم يُلغى فورًا، فاحفظ الجديد دائمًا.

ربط رقم واتساب #

قبل أي إرسال، لازم يكون فيه رقم واتساب مربوط بحساب مدعوم. الربط بيتم من لوحة واتساب بتدفّق Meta Embedded Signup — مش عبر الـ API العام.

تسجيل الدخول بميتا (Embedded Signup)

من لوحة واتساب بتفتح نافذة ميتا بصلاحيتَي whatsapp_business_management وwhatsapp_business_messaging. ميتا بترجّع code ومعاه sessionInfo فيه waba_id وphone_number_id.

تبادل الكود — POST /functions/v1/exchange-token

اللوحة بتبعت الكود للدالة، وهي بتبادله مع ميتا وبتخزّن توكن الوصول مشفّرًا في صف التكامل. الدالة بتتطلب جلسة Supabase (Authorization بجلسة المستخدم) — بلا ترويسة بترجع 401 بالشكل {"code":"UNAUTHORIZED_NO_AUTH_HEADER"}.

تسجيل الرقم — POST /functions/v1/register-whatsapp

جسم الطلب { "phoneNumberId": "…" } بجلسة المستخدم. الدالة بتقرأ حالة الرقم من Graph v25.0، وبتسجّله بـ PIN مولّد تلقائيًا لو محتاج تسجيل، وبتشترك في webhooks الـ WABA.

التحقق من الاشتراك في الـ Webhooks

الدالة بتقرأ الحقول المشتركة فعليًا وبترجّعها، وبتنبّه على أي حقل ناقص من المطلوبة: messages، smb_message_echoes، smb_app_state_sync.

تفعيل التكامل (من فريق مدعوم)

بيتسجّل تطبيقك كـ integration client، وبيتصدرلك مفتاح mad3_test_… للاختبار ثم mad3_live_… للإنتاج.

منع التكرار (Idempotency) #

idempotency_key إلزامي. اجعله معبّرًا عن الحدث نفسه لا عن لحظة الإرسال.

الحماية مفروضة في قاعدة البيانات (قيد فريد على client_id + idempotency_key) لا في كود التطبيق — فطلبان متزامنان تمامًا لا يمكن أن يُرسلا رسالتين. وmetadata خارج حساب التطابق: تغييرها وحدها لا يكسر إعادة المحاولة.

سياسة إعادة المحاولة

  • أعد المحاولة فقط عند retryable: true — وهي 429، 5xx، 402، وREQUEST_IN_PROGRESS.
  • استخدم نفس idempotency_key — هذا بالضبط ما يمنع الازدواج.
  • تراجع أُسّي: 2s، 4s، 8s، 16s — بحد أقصى 5 محاولات.
  • على 429 احترم ترويسة Retry-After بالثواني.
  • رموز جديدة قد تُضاف لاحقًا — عامل الرمز غير المعروف كخطأ غير قابل لإعادة المحاولة ما لم يقل retryable: true.

غلاف جاهز (SDK) #

كلاس بسيط بيلفّ الـ JSON-RPC، يعمل الـ parsing، ويطلّع أخطاء واضحة — أسهل من إعادة كتابة نفس الكود كل مرة.

class Mad3oomClient {
  constructor(token, baseUrl = "https://mad3oom.com/mcp") {
    this.token = token;
    this.baseUrl = baseUrl;
  }

  async call(method, params) {
    const res = await fetch(this.baseUrl, {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${this.token}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        jsonrpc: "2.0", id: Date.now(), method, params,
      }),
    });

    if (res.status === 429) {
      throw Object.assign(new Error("Rate limited"), { retryable: true });
    }

    const data = await res.json();
    if (data.error) {
      throw new Error(`[${data.error.code}] ${data.error.message}`);
    }
    return data.result;
  }

  async tool(name, args = {}) {
    const result = await this.call("tools/call", { name, arguments: args });
    // نتيجة الأداة نص JSON داخل content[0].text
    return JSON.parse(result.content[0].text);
  }

  listTools() {
    return this.call("tools/list").then(r => r.tools);
  }
}

import json, os, requests


class Mad3oomClient:
    def __init__(self, token, base_url="https://mad3oom.com/mcp"):
        self.token = token
        self.base_url = base_url

    def call(self, method, params=None):
        resp = requests.post(
            self.base_url,
            headers={
                "Authorization": f"Bearer {self.token}",
                "Content-Type": "application/json",
            },
            json={"jsonrpc": "2.0", "id": 1,
                  "method": method, "params": params},
            timeout=30,
        )
        if resp.status_code == 429:
            raise RuntimeError("Rate limited (60 req/min)")

        data = resp.json()
        if "error" in data:
            err = data["error"]
            raise RuntimeError(f"[{err['code']}] {err['message']}")
        return data["result"]

    def tool(self, name, args=None):
        result = self.call("tools/call",
                           {"name": name, "arguments": args or {}})
        # نتيجة الأداة نص JSON داخل content[0]["text"]
        return json.loads(result["content"][0]["text"])

    def list_tools(self):
        return self.call("tools/list")["tools"]

آخر التحديثات #

توحيد الدومين على mad3oom.com

  • كل نقاط OAoth والاكتشاف و/mcp بقت تُخدَم من mad3oom.com بلا أي إعادة توجيه.
