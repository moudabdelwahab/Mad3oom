01

ابدأ

مدعوم API بيدّيك وصول لحسابك كامل من خلال endpoint واحد بس:

POSThttps://mad3oom.online/mcp

تبعتله اسم الأداة اللي عايزها مع البيانات، وهو يرجّعلك النتيجة. نفس الرابط ده تقدر تحطه في Claude أو ChatGPT مباشرة لو حابب.

02

أنشئ مفتاح API30 ثانية

افتح "مفاتيح API"

من لوحة المطورين.

دوس "توليد مفتاح جديد"

اختار الصلاحيات (Scopes) اللي محتاجها.

احفظ الـ Key والـ Secret فورًا

بيظهروا مرة واحدة بس ومش هترجعلك تانى.

03

ابعت أول Requestدقيقة

هنجيب آخر التذاكر المفتوحة — انسخ، بدّل القيم، وشغّل.

اقرأ التذاكر 
curl -X POST https://mad3oom.online/mcp \
  -H "Authorization: Bearer YOUR_API_KEY.YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": { "name": "list_tickets", "arguments": { "status": "open", "limit": 5 } }
  }'
const res = await fetch("https://mad3oom.online/mcp", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY.YOUR_SECRET",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    jsonrpc: "2.0", id: 1, method: "tools/call",
    params: { name: "list_tickets", arguments: { status: "open", limit: 5 } },
  }),
});
const data = await res.json();
import requests

resp = requests.post(
    "https://mad3oom.online/mcp",
    headers={"Authorization": "Bearer YOUR_API_KEY.YOUR_SECRET"},
    json={
        "jsonrpc": "2.0", "id": 1, "method": "tools/call",
        "params": {"name": "list_tickets", "arguments": {"status": "open", "limit": 5}},
    },
)

استبدل YOUR_API_KEY وYOUR_SECRET بالقيم اللي حفظتها في الخطوة اللي فاتت.

الرد
Response
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [{ "type": "text", "text": "[ {...ticket}, {...ticket} ]" }]
  }
}

البيانات جوه result.content[0].text كنص JSON — اعملها JSON.parse() عشان توصل للمصفوفة. من هنا في الأمثلة الجاية هنعرضها بعد الـ parsing مباشرة.

جرّب الـ APIدقيقة

حطّ مفتاحك واضغط إرسال — الطلب بيروح من متصفحك مباشرة، من غير أي وسيط.

ما بيتخزّنش ولا بيتبعت لأي حاجة غير mad3oom.online/mcp.
فيه حد أقصى 60 طلب/دقيقة — استخدمه بحكمة أثناء الاختبار.

لو حصل خطأ

HTTPيعني إيهالحل
401المفتاح غلط أو منتهياتأكد من الـ Authorization header
200*الأداة مش من ضمن صلاحياتكضيف الـ scope من لوحة المفاتيح
404الحاجة مش موجودةتأكد من الـ id
429طلبات كتير بسرعة (أكتر من 60/دقيقة)استنى دقيقة وكمّل
500خطأ من عندناجرّب تاني، ولو استمر كلّمنا

* أخطاء الأدوات بترجع HTTP 200 مع error جوه الرد، حسب سبيك JSON-RPC.

07

إزاي شغّال من جوه

جدول api_tokens هو مصدر الهوية الوحيد — سواء ولّدته يدويًا، أو صدر تلقائيًا من OAuth.

توليد يدوي

من لوحة مفاتيح API

api_tokens

مصدر الهوية الموحّد

توليد تلقائي

عبر OAuth 2.1

كتالوج الأدوات بيتقرأ Live من قاعدة البيانات — أي تعديل بينعكس فورًا. وكل أداة بتفحص صلاحيات المستخدم (أدمن / عميل عادي) قبل ما تنفّذ.

08

OAuth 2.1 (Claude / ChatGPT)

لو بتبني Connector لعميل MCP خارجي، بدل ما تستخدم مفتاح ثابت.

الوظيفةPublic URL
DiscoveryGET /.well-known/oauth-authorization-server
Protected ResourceGET /.well-known/oauth-protected-resource
تسجيل عميلPOST /oauth/register
بدء التفويضGET /oauth/authorize
TokenPOST /oauth/token
تسجيل العميل

يبعت client_name وredirect_uris → يرجع client_id.

PKCE + موافقة المستخدم

code_challenge_method=S256 إجباري.

تبادل الكود بـ Access Token

ينشئ api_tokens جديد + refresh token.

الاستخدام والتجديد

Access token: ساعة. Refresh token: 30 يوم، يُدوَّر بالكامل عند كل استخدام.

Endpointالحد
authorize60/دقيقة لكل IP، 20/دقيقة لكل client
token40/دقيقة لكل IP، 15/دقيقة لكل client
register5/ساعة لكل IP
09

مدعوم كعميل MCP

ميزة داخلية للوحة الإدارة — مدعوم بيتصل بخوادم MCP خارجية (Supabase، GitHub...) نيابةً عن الأدمن. مش جزء من استهلاكك كمطوّر خارجي.
